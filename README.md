# 留白 · Focus Desk

一个在浏览器里使用的专注工作台：写下一件事，留出一段时间，再把分心的念头放进随手记。

源码正式保存于 `E:\Proj\Active\MyWeb\focus-desk`。本项目使用原生 HTML、CSS 与 JavaScript，构建产物为 `dist/` 中的五个静态文件，无第三方运行或构建依赖。

## 功能

- **任务清单**：添加、完成、恢复和删除任务，按全部、待办或完成筛选；可将待办选为当前专注任务。删除任务与清理已完成任务会保留专注记录。
- **专注计时**：默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，可分别设置为 1–120 分钟；支持开始、暂停、继续和重置。切换任务、模式或时长时，若存在未完成计时，会先确认是否重置。
- **随手记**：边写边保存，记录暂时不想处理的念头。
- **今日与近 7 天统计**：显示今日专注分钟数、完成段数、当前清单中今日完成的任务数，以及近 7 天的专注时长。日期按浏览器所在时区划分；只有完成的专注段计入时长，休息和未完成的计时不计入。
- **提示音与备份**：设置中可开启完成提示音，并导出或导入 JSON 备份。

完成一段计时后不会自动开始下一段。计时按结束时间戳计算，刷新或切回页面时会结算已到期的计时，避免后台标签页降频导致倒计时变慢。页面隐藏时停止刷新循环；关闭页面、浏览器休眠或音频受限时，不保证后台提醒或提示音，恢复页面后才会显示结算结果。

## 本地运行

需要 Node.js 22 或更新版本；预览命令另外需要 Python 3。项目没有 npm 依赖，无需先运行 `npm install`。

在源码目录执行：

```powershell
npm run check
npm run test
npm run build
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:4173/`。修改源码后重新运行 `npm run build` 并刷新页面；静态服务结束时按 `Ctrl+C`。

`check` 检查两个 JavaScript 模块的语法；`test` 使用 Node.js 自带测试运行器；`build` 将 `src/` 中的页面、样式、两个模块和图标复制到 `dist/`。

## 数据与备份

任务、便笺、时长设置、计时状态和专注记录保存在当前浏览器的 `localStorage`（键名 `focus-desk:v1`），提示音偏好另存于 `focus-desk:sound`。应用没有账号、远端数据库或跨设备自动同步。

浏览器按 origin（协议、主机和端口）隔离数据：本地预览、Sites 和 Vercel 地址各自独立；即使同一台电脑，换浏览器或更换本地服务端口，也不会自动读取原来的记录。同一 origin 的多个标签页会接收彼此的存储更新。

在“设置与备份”中导出 JSON，再到目标浏览器或新地址导入，可迁移任务、便笺、计时和专注记录；提示音偏好不包含在备份中。导入会先校验文件，并在确认后替换当前数据，建议先导出一份现有备份。备份文件需小于 1 MB；数据上限为 200 项任务、10,000 字便笺和最近 500 段专注记录。

清除网站数据、浏览器限制存储或移除浏览器配置会影响本地记录。保存失败时页面会提示导出备份。清理已完成任务后，今日完成任务数会随当前清单更新，专注段数与时长仍保留。

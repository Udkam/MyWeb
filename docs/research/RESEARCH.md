# 苔光小筑：开发前调研

访问日期：2026-10-13。实际打开并阅读 **61 个独立游戏作者/官方网站页面**，其中 **54 个有明确 Web 游戏入口**，另外 7 个仅作下载版或 HTML 文件参考。不是把搜索结果算作访问，也不宣称完整试玩 50 款。三组原始记录包含可核查的页面证据、方法和局限。

## 结论及落实

1. **让离开成为休息。** [Isla](https://minmax.itch.io/isla) 与 [Cat Cove Inn](https://loaflabs.itch.io/cat-cove-inn) 提供了不同维护负担的对照。我们的设计选择是伙伴不饥饿、不死亡、不因缺席扣资源；离线只积累营地产出，最多保存 8 小时。
2. **短途探索推动可见成长。** [Driftline](https://yliu84.itch.io/driftline) 的收集与设施循环、[Spring Lullaby](https://tiidy-shell.itch.io/spring-lullaby) 的环境变化启发了营地建设。采用 6 个地点的一次远行，木材和石料换来画面中真实变化的设施。
3. **少量选项也能产生变化。** [Forward](https://twotinydice.itch.io/forward) 的简短路径与 [Dungeon Deck](https://incinious.itch.io/dungeon-deck) 的卡牌机制支持小选择集。采用可预见风险的路线与回合制战斗，每步最多 3 个主要按钮。
4. **先给一个动作，再展开系统。** [A Dark Room 官方资料](https://press.doublespeakgames.com/adr/index.html) 描述渐进式交互。首次进入先看到营地和出发按钮；图鉴、升级、伙伴在同一页面按需查看。
5. **持久记录是玩法的一部分。** 多个放置游戏页面强调保存与长期成长。每个动作后保存完整随机状态、旅程和收获，提供可验证的导入导出，不能靠刷新重复领取。
6. **手机操作不考验手速。** [Marufuwa Fishing Days](https://ao-hozumi.itch.io/marufuwa-fishing-days) 作者描述轻松垂钓；额外实际打开其 Web 版并操作 Cast、Reel in、Now，看到失手可重试的反馈。这里只作短交互观察，没有完整试玩或验证其存档。本作采用无计时压力的大按钮回合制。

以上借鉴属于本项目的设计推论，不表示所有参考游戏都具备上述实现。

## 第一轮候选方向（第二轮研究中，未定案）

**苔光小筑 / Mosslight**：像素森林营地 + 轻肉鸽远行。每次随手玩几分钟，带回材料，升级小屋，结识伙伴、收藏林间小物。旅途中可以随时回家，倒下也保留已获得的材料。没有每日任务、连续签到、体力付费或缺席惩罚。

美术使用下载的 Kenney Tiny Town / Tiny Farm / Tiny Dungeon；音乐使用 Bobjt 的 Peaceful Ville；交互音效使用 Kenney 的 CC0 资源。下载信息和许可单独保存。

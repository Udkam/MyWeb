# 原研究笔记精选

此目录保留四组研究的原始分析文字与人工逐页笔记精选，不复制网页全文、HTML 或抓取缓存。所有样本是否计数只由上级目录的四组最终台账决定。

- `root-analysis.md`：root 的阶段观察与阅读范围，原样副本。
- `bullet-brief-001-050.md`、`bullet-brief-051-100.md`、`bullet-brief-101-140.md`：bullet 三批阶段简报，原样副本。
- `dungeon-analysis-01.md`、`dungeon-analysis-02.md`：dungeon 两批比较，原样副本。
- `arena-brief-050.md`、`arena-brief-100.md`：arena 两批比较，原样副本。
- `root-selected.jsonl`、`bullet-selected.jsonl`、`dungeon-selected.jsonl`、`arena-selected.jsonl`：每组 12 条、合计 48 条逐页人工笔记精选，全部能对应合并台账；附原文件和原行号，bullet 的 JSON 数组则使用从 0 开始的 `source_item_index` 定位。`original_note` 保留选中笔记原内容。
- `identity-audit.json`：最终 532 条身份审计原样副本。

精选覆盖动作资源、行为组合、风险选择、局长、长期保留及页面所披露的限制，用于快速复核来源，不代表对作品质量排名。台账保留全部 532 条 `observed_mechanics`，没有用精选替代其余记录。

简报中的 50／100 条进度、旧总数目标、尚待复查措辞和当时的“未试玩”均保留为历史上下文，不作今日状态的重新断言。上级目录独立报告补充了四款有限实际交互与一次失败启动，各自边界以对应报告为准。

部分历史简报提到未计数的官方参考、对照或 excluded；只作为当时的分析背景。它们没有因为文档被复制而加入 532 条，也不会成为新的计数入口。每个副本的原始文件 SHA-256 和交付 SHA-256 均在上级 `manifest.json` 中。

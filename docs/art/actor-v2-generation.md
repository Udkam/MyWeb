## 导入合同

运行 `python scripts/import_actor_v2.py`，依赖当前已有的 Pillow 与 NumPy，无新增安装。选定原图在 `.local/assets/actors-v2`，其他同行制作交接源在 `.local/assets/musket-v2-source` 与 `.local/assets/sword-v2-source`。每个选定源的 SHA256、真实画布、完整连通区域、原始人数、实际选用人数、alpha 阈值和站姿参考高度在 [actor-v2-audit.json](actor-v2-audit.json)。

导入只做完整 alpha 连通区域隔离、统一每条源的缩放、最近邻采样、脚点与握点元数据、可变矩形打包。alpha 小于 128 的残留归零，保留样本 alpha 统一 255；不修画人体或武器、不补色、不量化色板、不按刀尖居中。每条动作源使用共同站姿参考高度，俯身与倒地不拉伸。640 版本参考身体 70px，960 版本从同一高分源独立采样为 105px；后者不是放大 640 PNG，也不能证明生成源拥有原生 1px 网格。

身体与武器分离。所有运行身体没有烘焙刀枪。`frame.weapon.hand` 为身体矩形内的握点，`angle` 为屏幕坐标顺时针弧度；以 `weapon.pivot` 旋转同一完整源。层级为身体、武器、原身体手部区域；双手枪用 `handOcclusionRects` 覆盖主握与支撑手。地面释放的枪没有手部遮盖。镜像必须把身体、脚点和武器作为同一组翻转。

`public/assets/actors-v2/manifest.json` 是画面元数据；同一次导出生成 `contact-geometry.json` 与 `src/game/art-contact-data.ts`，包含 manifest SHA256、源 SHA、无四舍五入的脚点局部握点/刀根/刀尖/前掌/枪口及逐帧身体 bbox。后两者只能从导入脚本重生，不能手改数值。

当前明确时钟：闪避 60/60/60/40/40ms，共 260ms，无敌 60–180ms；第一刀 100/80/240ms，第二刀 150/110/300ms，空中刀 35/120/145ms，推撞 120/100/250ms；刀兵 520/150/650ms、brace80/80ms、retreat75/75ms循环、hurt160/80ms；火枪手瞄准 1000ms、开火 120ms、装填 1700ms。

高台火枪瞄准/开火的实际枪管轴固定向前下14°，即0.2443460952792061弧度。源枪自身轴有约0.04476°下倾，所以身体帧上的渲染角为0.2435648454381518；不是直接把渲染角误当实际弹道。发弹用同源fire枪口与barrelAngle，锁向后不能重新朝玩家计算角度。火枪手失衡与被推明确别名为hurt，不计为新帧。

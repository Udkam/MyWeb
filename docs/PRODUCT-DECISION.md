# 产品决策 · SpriteLab

2026-10-16。用户选择三个候选中的第二项：亲手创作像素角色与动作。目标是公开即用的专业创作工作台，价值来自用户对造型、姿态、节奏和效果的判断。

## 研究依据与取舍

重新对照三类一手资料，核实编辑、交付和使用三个环节；本轮不把页面数量当作用户需求证据，不声称未进行的用户访谈或市场验证。

1. [Piskel 官方产品页](https://www.piskelapp.com/)：浏览器像素编辑、实时预览、PNG/ZIP 导出是已经成立的工作流。SpriteLab 不声称发明像素编辑器，选择中文直接进入工作台、可编辑的动作示例与实际试跑作为较集中的体验。
2. [Aseprite 精灵图文档](https://www.aseprite.org/docs/sprite-sheet/)：精灵图是多帧的空间排列，导入需明确帧尺寸、排列与间距。当前实现清楚限定无间距规则网格，保留透明底和整数放大，不猜测任意不规则图集。
3. [Phaser 纹理概念](https://docs.phaser.io/phaser/concepts/textures)：引擎需要图像区域与帧索引，动画还需要时序。导出提供 PNG、明确的帧矩形和独立停留时长；不以“下载一张图”冒充完整动画交付，也不宣称未经测试的引擎导入兼容。

以上为产品范围依据；不是复制上述网站的界面、源码或示例美术。模板和舞台为本项目原创，fflate 是唯一第三方运行库且保留许可。

## 核心使用路径

打开网站 → 在示例或空白画布上画 → 复制/改动下一帧 → 调节节奏 → 循环预览与试跑 → 下载可编辑项目及游戏素材。

所有能力围绕这条完整路径。初始页面直接是工作台；中文说明在需要时展开；不添加登录、积分、生成式 AI、社交信息流或与创作无关的面板。

## 完成标准

可绘制、可撤销、可复原、可重新导入，文件像素和时长与编辑状态一致。实际浏览器测试必须操作界面并独立解码下载文件。小屏检查通过触屏模拟验证，不能据此声称已实测所有手机硬件。公开部署需另行验证生产路由和所有运行资源哈希。

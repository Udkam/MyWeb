# 从方案到完整公开游戏

## 0 · 执行对话启动

在本目录核对Git根与 `codex/game-next`。用户已明确授权新对话以 GPT-6.1-sol／ultra 开启goal执行；先 `create_goal`，目标覆盖方案选择、完整制作、验证、公开部署和MyWeb挂载，不添加用户未请求的token预算。

先阅读本包，让独立子代理审查三个候选的核心乐趣、差异化、资产负担、范围与部署。优先推荐Wild Circuit，但新对话可有理由地另选一个。写 `docs/DECISION.md`，固定工作名／公开英文名、核心循环、发布内容表和首个验证切片。复核完成后进入制作，不等待用户手工交接，不同时开发三款。

## 1 · 核心与视觉证明

完成能实际操作的90秒切片：移动、独特动词、敌人反应、第一次成长、一次失败／重启。用真实拟采用角色、场景、音效和镜头验证；Blender资产按本机技能走一次完整源文件→导出→引擎→截图检查。

检查玩家是否有判断、增长是否可见、动作是否清楚、手机输入是否成立。不是仅渲染漂亮封面，也不是留下粗糙几何后直接扩产。一轮有根据的修正后固定方向；若核心不可行，把原因和替代记录在决策中。

## 2 · 完整一局

实现地图连接、遭遇、成长选择、Boss、结算、返回基地、再开一局与存档。公开可玩骨架可以提前部署验证，但不能将此阶段当作任务完成。运行态须能通过开发用只读状态接口和确定步进复现。

## 3 · 发布内容与打磨

按已选内容表完成各区域、敌人／Boss、支线秘密、局外解锁、图鉴或装配、结局、挑战种子和分享战报。用不同构筑跑完整流程，难度应让高水平操作和普通玩家都能理解成功与失败的原因。

美术、音乐、镜头、受击反馈、加载状态、教程、触控、键盘焦点、语言切换、静音、暂停和存档都属于游戏组件，不以“功能已写”替代打磨。整页适配全视口，避免滚动条与控件盖住战斗。

## 4 · 验收

使用锁文件干净安装、语法／类型检查、适当的模拟测试、构建；在真实浏览器实际走通：

- 首次开始 → 教学 → 第一次成长 → 区域目标 → 所选方案的终局挑战 → 胜利／失败 → 结算 → 局外变化 → 再开一局。
- 所选方案的至少4种有效构筑或等价玩法路线；战斗方案验证Boss不同阶段与反制，航行方案验证不同载货／航线及风暴应对；碰撞、目标、奖励和出口可达。
- 暂停／恢复、刷新续玩、导出／导入、坏存档、语言／音量／画质保存、重开后资源释放。
- 桌面、320px小屏、手机竖横切换、常见笔记本画面和全屏退出；音频在用户交互后成功播放。
- 正常与压力场景的帧时间、GPU／绘制预算、资源大小、控制台错误；记录实体设备与模拟环境的边界。

`render_game_to_text()` 描述真实当前状态，`advanceTime(ms)`支持确定步进。使用 develop-web-game 的现成客户端和动作格式；另加有必要的界面／IO测试。查看截图与状态，不只读绿色测试数量。

## 5 · 发布选择

首选 **独立Vercel静态项目**，绑定 `Udkam/MyWeb` 的 `codex/game-next`、正确构建根与产物目录；先验证preview，再确认production。不得把新游戏绑定到MyWeb目录main，也不改动现有TetraMorph项目的部署分支。

2核8GB服务器适合Nginx静态文件和一个小型API／SQLite（如后来确需每日种子、异步成绩或跨设备存档）。浏览器执行3D模拟和绘制，服务器不用承担游戏渲染。服务器的OS、带宽、负载和访问条件未核查，不承诺在线人数，也不因此先上账号与多人架构。

[Vercel官方说明](https://vercel.com/kb/guide/do-vercel-serverless-functions-support-websocket-connections)现支持Functions原生WebSocket public beta／Fluid Compute；不能沿用“完全不支持WebSocket”的旧结论。但连接受函数时长、重连实例与共享状态约束，首版不需要它。[Functions限制](https://vercel.com/docs/functions/limitations)、[部署限制](https://vercel.com/docs/limits)应按实际账户和发布方式复核，不臆测免费容量。

Vercel不可用时，可在已有授权／连接内使用服务器或ChatGPT Sites。使用Sites先读当前 sites 技能；只作为实际通过发布与访问测试的平台，不承诺未经验证的后台能力。现有Cinder Below的Sites备用不得覆盖。缺失关键登录权限时明确报告实际阻碍，继续完成独立可做的工作，不伪造上线。

资源同源、自托管字体和解码器、无运行时付费模型依赖。不同域名的浏览器存档不自动互通，提供导出／导入。失败部署与当前线上状态分开判断，保留已验证版本可恢复。

## 6 · MyWeb挂载与完成条件

若采用入口站同源静态快照，新增专用精确提交导入脚本、资源哈希与release记录；独立源目录继续维护，不能直接编辑public快照。

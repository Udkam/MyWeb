# SpriteLab 验收记录

2026-10-16，公开部署前验收。

## 本地

- UTF-8、所有 JavaScript 模块语法、105 个 UI 控件引用和本地资源链接检查通过。
- 61 项 Node 测试通过：像素与合成、数据校验、撤销历史、PNG/ZIP、逐帧播放、物理试跑、绘画事务、切帧同步和异步保存。
- 真实 Chromium IO 验收 39 项通过：从界面导入 PNG、拆帧、调时长、下载全部格式、重导入、刷新恢复草稿。实际下载由 Pillow、zipfile 独立解析。
- UI 验收覆盖 1440、390、320 像素视口，实际鼠标、键盘和浏览器模拟触屏。绘画、工具、图层、动作、帧、撤销、选区移动与导出有实际下载内容断言。手机结果代表浏览器模拟，不等同于所有真机验证。
- 各动作有独立帧数据；改动复制帧不会改变原帧；普通编辑保留预览已播放时间；双触点切帧先收尾原笔画。
- 低 alpha PNG 样本直接编解码，避免 Canvas 预乘量化；原始样本、Adam7、调色板、灰度、16 位转 8 位及五种滤波均有独立输入验证。
- 构建产物仅 11 个静态运行文件，无外部字体/CDN、用户文件上传、登录或后台服务。

证据保存在 `.qa/io-acceptance/`、`.qa/ui-acceptance.json` 与 `.qa/ui-*.png`；不进入公开快照或 Git。

# Cutlass Wake · 美术方向与实际取舍

2026-10-24。当前只完成素材基线与单屏审核候选，用户视觉认可尚未取得。

## 先看实物

本地评审图：`.local/art/art-board-a.png`、`art-board-b.png`。二者使用相同 640×360 逻辑港口构图，角色与火炮同框，场景按 2× 最近邻展示，底部人物条按原生 1× 展示。它们是实际资源的静态组合，不是运行录像，也不是画面已验收的声明。

A 使用 Pixel Frog / Treasure Hunters 的统一 CC0 资源。完整验包后，主角身体只有 25–28px；三种敌人是海洋生物，远程比较用贝壳炮台，不能当作人类火枪手。缺少专用防御、招架、推击和闪避。虽然体系统一，角色细节和叙事方向不足以直接作为本作最终基底。

B 使用本轮原创生成的人物、环境和道具，经透明度、完整连通轮廓、逐帧身体枢轴检查后技术导入。当前待机有效身高为主角 57px、持刀船员 56px、火枪手 57px；画布统一为 96×80，脚底锚点 (36,68)，没有把 96×80 画布冒充人物身高。选择 B 作为小样片候选，原因是人类角色、体量、配色和港口层次更接近制作方案。此选择只授权单屏实机比较，不冻结最终画风。

SeaHook Basic 已实际取得，32px 地形、背景和动画水面可用，许可 CC-BY 4.0；它没有角色。hippo Pirate 的待机身体约16px，不适合本次精细路线。二者保留为研究来源，不混入 B 的运行角色。

## 画面与比例

- 主角深蓝外套、珊瑚围巾、象牙色钢刀；持刀船员用白衬衣/暗红头巾/赭色腰带，火枪手用灰绿外套/三角帽/长火枪。轮廓和持械区分职责。
- 港口使用暖金天空、淡紫远山、青绿海面与红褐木板。远船、城镇、仓库分层；交战平面保持清楚。没有以大烟雾、泛光或黑暗遮挡动作。
- 世界为640×360；地面碰撞边y255。实体木箱为48×24，单向高台边112×12，托架图形属于装饰，不误报为碰撞。
- 物理保留浮点，显示位置取整；世界纹理最近邻采样。显示按设备像素的整数倍率居中，边框有意保留。手机中文HUD与按钮独立于世界像素，不缩为小号像素字。
- 手机横屏把控件放在侧边和甲板下方的水面空间，避免压缩世界高度和盖住脚底。触控提示使用「防／攻」而非K/J。

## 生成与导入的真实边界

生成工具没有遵守提示词要求的严格4px网格和有限色板，不能把提示词当事实。两张1536×1024人物源图也不符合整齐6×4裁格：刀刃、脚底越格。导入按alpha≥128的24个独立完整轮廓逐个提取，按手工复核的身体枢轴统一1/4最近邻采样，保留刀尖，不逐帧拉伸。生成源、导入参数、每帧bbox与SHA见 `art/generated-frame-audit.json`。

目前仍有细碎颜色、部分姿态刀长投影不一致、跪地恢复接触不统一、装填通条不够明确。闪避尚用起跳蹲姿，死亡只有受击与倒地关键姿态；没有完整独立闪避/互动/连续死亡动画，更没有Boss素材。这些缺口必须在扩章节前落实；不能把少量姿态称为完整动作库。

当前美术决策点：先审实际素材拼板，再审15–20秒真实运行样片及死亡重开片段。用户未认可前，Goal保持active，停止全量内容扩展。
